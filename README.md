# Reservio

Univerzálny rezervačný systém pre kaderníčky, kozmetičky, trénerov, tanečné školy a kliniky.

## 🎯 Cieľ projektu
Jednoduchá, moderná a univerzálna apka, ktorá umožní zadávateľom spravovať služby, termíny, prestávky, obedy a individuálne dĺžky klientov.

## 🧱 Technológie
- Next.js (React)
- Firebase (Auth + Firestore)
- Tailwind CSS
- Vercel (deploy)

## 🚀 Roadmap
1. Základný HTML dizajn
2. Inicializácia Next.js projektu
3. Kalendár a rezervácie
4. Prestávky, obedy, interné bloky
5. Individuálne dĺžky klientov
6. Notifikácie a denné súhrny
